# 🎨 Design System Studio (`src/features/design-system`)

## Overview
Centralized design token management system and motion-ready component library (Pill Buttons, Glass Cards, Haptic Toggles, Dialog Modals).

---

## 🚀 Key Capabilities
- **Complete Token System**: Colors, typography scales, spacing, border radii, and elevation shadows.
- **Component Showcase**: Pre-animated UI components previewed with live tokens.
- **CSS Custom Property Exporter**: Exports tokens as CSS variables (`--color-primary`, `--radius-md`).
