# 📋 Copy & Paste Engine (`src/features/copy-paste`)

## Overview
Low-level clipboard interchange serialization formats for Adobe Premiere Pro, After Effects, and standard system text clipboards.

---

## 🚀 Key Capabilities
- Adobe After Effects clipboard text serialization (`Adobe After Effects 8.0 Keyframe Data`).
- Adobe Premiere Pro ExtendScript keyframe formatting.
- Universal JSON interchange payloads for local file and cross-tab pasting.
