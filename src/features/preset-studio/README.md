# 🏛️ Preset Studio (`src/features/preset-studio`)

## Overview
Preset browsing, category tagging, and layer morphing management.

---

## 🚀 Key Capabilities
- Preset tagging: *Tactile UI, Cinematic Elegance, Social Punch, Minimal*.
- Multi-layer preset application with automatic stagger offsets.
- Preset import/export as JSON bundles.
