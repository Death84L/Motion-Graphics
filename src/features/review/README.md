# 👥 Synchronized A/B Review & Version History (`src/features/review`)

## Overview
Side-by-side synchronized version comparison viewport for evaluating motion variations with version snapshot history.

---

## 🚀 Key Capabilities
- **Synchronized A/B Viewport**: Dual viewports playing Version A and Version B simultaneously.
- **Snapshot History**: Saves dated motion snapshots with user notes and 1-click restoration.
- **Visual Difference Highlights**: Color-coded trajectory difference overlay.
