# 📱 UI Motion Studio (`src/features/ui-studio`)

## Overview
Tactile UI micro-interaction playground simulating buttons, cards, menus, and bottom sheets under realistic spring physics.

---

## 🚀 Key Capabilities
- Touch gesture emulation (tap, pinch, drag, fling).
- Haptic bounce feedback curves.
- Instant export to React Native and Framer Motion code.
