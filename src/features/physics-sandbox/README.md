# 🧪 Physics Motion Sandbox (`src/features/physics-sandbox`)

## Overview
Interactive 2D physics sandbox simulating falling, colliding, and bouncing bodies under real-time Gravity, Mass, Friction, and Restitution.

---

## 🚀 Key Capabilities
- **Live 2D Physics Simulator**: Interactive viewport simulating falling and bouncing Balls, Boxes, and Pills.
- **Physics Tuning Controls**: Real-time sliders for *Gravity ($g$), Restitution (bounciness), Mass ($m$), and Friction*.
- **Physics-to-Curve Exporter**: Converts the simulated trajectory directly into editable Bézier KeyframePoints for Premiere or After Effects.
