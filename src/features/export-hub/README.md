# 📦 Universal Export Hub (`src/features/export-hub`)

## Overview
Comprehensive multi-platform exporter generating code and data for video editors, web developers, mobile apps, and game engines.

---

## 🚀 Key Capabilities
- **Video Hosts**: Adobe Premiere Pro (UXP), Adobe After Effects (JSX), DaVinci Resolve (Fusion).
- **Web & Apps**: CSS `linear()`, CSS `@keyframes`, GSAP `CustomEase`, Framer Motion, WAAPI, Lottie JSON.
- **Game Engines**: Unity C# `AnimationCurve`, Unreal Engine 5 `FRichCurve`.
