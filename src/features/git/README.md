# 🔀 Animation Git & Kinematic Diff (`src/features/git`)

## Overview
Git-style version control and kinematic motion diffing studio for non-destructive animation experimentation.

---

## 🚀 Key Capabilities
- **Branching System**: Create and switch between animation variations (`main`, `cinematic-drift`, `social-snappy`, `client-v2`).
- **Kinematic Motion Diff**: Calculates parameter deltas between branches: Duration ($\Delta t$), Energy ($\Delta E$), Overshoot ($\Delta OS$), and Peak Velocity ($\Delta v$).
- **Visual Version Comparison**: Visualizes branch curves overlaid on top of each other.
