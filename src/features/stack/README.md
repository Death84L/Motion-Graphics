# 🧱 Procedural Modifier Stack (`src/features/stack`)

## Overview
Non-destructive modifier layering engine applying springs, continuous noise wiggles, and periodic oscillations over base keyframes.

---

## 🚀 Key Capabilities
- **Modifier Types**: Spring Overshoot, Noise Wiggle, Periodic Sine/Cos, Stepped Quantizer.
- **Independent On/Off Toggles**: Enable/disable modifiers without destroying base curves.
- **Additive & Multiplicative Blend Math**: Blend modes for combining modifier outputs.
