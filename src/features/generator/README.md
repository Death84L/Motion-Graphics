# 🪄 Procedural Motion Generator (`src/features/generator`)

## Overview
Zero-cost parametric motion generator that synthesizes infinite variations of natural motion curves from physical dials without invoking external cloud APIs.

---

## 🚀 Key Capabilities
- **6 Physical Sliders**: Energy, Elasticity, Smoothness, Overshoot, Aggression, Duration.
- **Directional Trajectory Pads**: Directs procedural curve synthesis along X, Y, Scale, or Rotation axes.
- **100% Free & Local-First**: Generates Bézier mathematical keyframes in browser memory in under 1 millisecond.
