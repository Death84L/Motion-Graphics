# 🔮 Real-Time VFX Shaders (`src/features/vfx`)

## Overview
GPU-accelerated visual effects shaders applied in real time over animated composition elements.

---

## 🚀 Key Capabilities
- **Shaders**: Gaussian Motion Blur, Glow Bloom, Drop Shadows, Chromatic Aberration.
- **Dynamic Parameter Drivers**: Animate blur radius and glow intensity directly from keyframe velocity.
