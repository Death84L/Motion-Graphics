# 🎞️ Multi-Track Animation Timeline (`src/features/timeline`)

## Overview
DAW- and NLE-style multi-track timeline displaying tracks, keyframe diamonds, property sub-channels, and work area markers.

---

## 🚀 Key Capabilities
- **Multi-Track Lanes**: Visual track lanes for text, shapes, captions, images, and video clips.
- **Expandable Property Sub-Channels**: Inspect sub-lanes for Position X/Y, Scale, Rotation, Opacity, and Blur.
- **Work Area Loop In/Out Markers**: Set custom playback loop regions.
- **Draggable SMPTE Time Scrubber**: Frame-accurate and millisecond-accurate playhead scrubber.
