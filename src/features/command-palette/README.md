# ⌘K Global Command Palette (`src/features/command-palette`)

## Overview
Keyboard-first global command palette providing instant fuzzy-search navigation and quick action launching across all Motion Studio tools.

---

## 🚀 Key Capabilities
- Triggerable via **⌘K** (macOS) or **Ctrl+K** (Windows/Linux).
- Fuzzy search across navigation targets (`> Switch to Motion Graph`, `> Open Caption Studio`).
- One-click action execution (`> Apply to Premiere Pro`, `> 1-Click Auto-Fix Jerk`, `> Save .motionstudio Project`).
- Global shortcut listener with automatic input/textarea guard.
