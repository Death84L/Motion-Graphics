# 📚 Visual Motion Library (`src/features/library`)

## Overview
Visual card-based motion library presenting structured motion recipes with live interactive preview canvases, duration readouts, and 1-click track application.

---

## 🚀 Key Capabilities
- Categorized taxonomy: *Tactile UI, Cinematic Elegance, Social Punch, Minimal*.
- Live preview canvas on hover showing motion behavior.
- Direct 1-click recipe application to active keyframe tracks.
