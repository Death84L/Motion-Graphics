# 🌌 2.5D / 3D Scene & Camera Studio (`src/features/scene3d`)

## Overview
Z-depth multi-plane compositor with 3D camera dolly, handheld shake simulation, and real-time particle effects.

---

## 🚀 Key Capabilities
- **Z-Axis Depth Hierarchy**: Position layers along Z-depth planes for true parallax perspective.
- **3D Camera Rig**: Controls Dolly (Z), Pitch (X), Yaw (Y), and Field-of-View (FOV).
- **Cinematic Handheld Camera**: Simulates organic subtle camera shake with Perlin noise algorithms.
- **2D Procedural Particles**: Real-time Sparks, Confetti, Dust, Stars, and Floating Bubbles.
