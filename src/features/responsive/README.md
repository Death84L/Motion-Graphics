# 🎯 Responsive Motion & Multi-Screen Constraint Lab (`src/features/responsive`)

## Overview
Automated constraint solver adapting 16:9 Landscape animation into 9:16 Vertical Reels/Shorts and 1:1 Square formats.

---

## 🚀 Key Capabilities
- **Multi-Aspect Ratio Adaptation**: Converts animations across 16:9, 9:16, 1:1, and 4:5 ratios.
- **Focal Anchor Preservation**: Preserves relative speeds, focal points, and boundary margins.
- **Dynamic Scale Re-mapping**: Re-computes travel distances to prevent off-screen clip clipping.
