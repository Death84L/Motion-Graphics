# 🧠 Motion Logic Graph (`src/features/logic-graph`)

## Overview
Visual node-based motion programming environment connecting inputs, mathematical transformations, audio analyzers, and target layer properties.

---

## 🚀 Key Capabilities
- **Node-Based Dataflow**: Connect output ports to input parameters across an infinite visual canvas.
- **Math & Logic Nodes**: Add, Multiply, Clamp, Lerp, Smoothstep, If/Condition, and Delay Frames.
- **Audio-Reactive Nodes**: Route live audio bass, mid, or treble frequencies into layer scale and glow bloom.
