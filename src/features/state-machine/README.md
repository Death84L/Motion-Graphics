# 🎭 Animation State Machine (`src/features/state-machine`)

## Overview
Interactive UI component state machine builder modeling transitions between `IDLE`, `HOVER`, `PRESSED`, `ACTIVE`, and `DISABLED` states.

---

## 🚀 Key Capabilities
- **Interactive Component Playground**: Test real-time cursor interactions and spring transitions.
- **State Transition Matrices**: Custom duration, damping, and scale targets per state change.
- **Framer Motion Exporter**: Generates production-ready React Framer Motion variant objects with spring physics parameters.
