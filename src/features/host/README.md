# 🔌 Unified Host Interchange (`src/features/host`)

## Overview
Consolidated, scalable host application integration connecting Motion Studio to Adobe Premiere Pro, Adobe After Effects, DaVinci Resolve, Final Cut Pro, and Web / Lottie.

---

## 🚀 Key Capabilities
- **Unified Single Export Trigger**: A single **`⚡ Export ▾`** dropdown menu consolidating all host dispatches.
- **Native Live Premiere Pro (UXP)**: Direct ExtendScript keyframe injection into Premiere Pro timeline clips.
- **After Effects JSX Exporter**: Generates atomic, undo-safe JSX ExtendScript animation blocks.
- **DaVinci Resolve Fusion Splines**: Formats frame-accurate Lua Fusion Spline tables.
- **Non-Destructive Keyframe Insertion**: Supports `merge-preserve` to update curve handles without wiping existing timeline keyframes.
