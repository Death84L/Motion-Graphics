# 🎥 Live Canvas & Composition Stage (`src/features/composition`)

## Overview
Interactive visual viewport stage for arranging, previewing, and manipulating composition layers in real time.

---

## 🚀 Key Capabilities
- **Aspect Ratio Switcher**: 16:9 (YouTube), 9:16 (TikTok/Reels), 1:1 (Square), 4:5 (Portrait).
- **Broadcast & Social Safe Zones**: 90% Action Safe and 80% Title Safe boundary guides.
- **On-Canvas Transform Gizmo**: Direct visual dragging of element Position, Scale, and Rotation.
- **Onion Skinning & Motion Trajectory Trails**: Renders ghost frames and path ribbons with velocity arrows.
