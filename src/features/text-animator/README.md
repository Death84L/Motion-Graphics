# 📝 Text & Kinetic Typography Animator (`src/features/text-animator`)

## Overview
Granular kinetic typography studio capable of animating text by Character, Word, Line, or Paragraph with 8-directional spatial staggering.

---

## 🚀 Key Capabilities
- **Granular Text Tokenizer**: Animate text by character, word, line, or block.
- **8-Directional Staggering**: Left-to-Right, Right-to-Left, Center-Out, Outside-In, or Sine waves.
- **Dynamic Typewriter Simulator**: Blinking cursor, variable typing speed, and punctuation pauses.
- **Kinetic Elastic Snapping**: Per-character physics spring reveals with tracking expansion.
