# 🌊 Easing Studio & Functions (`src/features/easing`)

## Overview
Comprehensive mathematical library and UI presets for classical, physics-based, and parametric easing curves (Cubic Bézier, Quad, Quart, Expo, Elastic, Bounce, Spring, and Back).

---

## 🚀 Key Capabilities
- **Standard Easing Presets**: Ease In, Ease Out, Ease In-Out with customizable curvature strength.
- **Harmonic Spring Equations**: Damped harmonic oscillator ($m\ddot{x} + c\dot{x} + kx = 0$) evaluating settling time, stiffness, and mass.
- **CSS `linear()` Compiler**: Converts complex arbitrary physics curves into standard CSS `linear()` easing strings for modern browsers.
- **Elastic & Rebound Bounce Solvers**: High-precision coefficient of restitution bounce generators.
