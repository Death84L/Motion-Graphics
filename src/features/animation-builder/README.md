# 🧱 Modular Animation Builder (`src/features/animation-builder`)

## Overview
Visual block-based animation sequencer building multi-step motion sequences (*Entrance $\to$ Emphasis $\to$ Exit*) without plotting raw keyframe curves manually.

---

## 🚀 Key Capabilities
- **Stage Sequencer**: Compose Entrance, Emphasis, and Exit motion blocks.
- **Parametric Block Tuning**: Direction, distance, duration, and ease controls per block.
- **1-Click Bézier Baking**: Compiles the block sequence into native Bézier keyframe curves.
